Instructions

1. Element Map

Smooth Scroll (Lenis)
‍
- Where: All pages, desktop only (screens 768px and wider)
- Target: The whole page, no element needed
- Code block: SMOOTH SCROLL
Number Counter
‍
- Where: Multiple pages across the template, wherever a number with the class "counter" is used (for example the stats and numbers sections)- Target: Any text element with the class "counter" and the custom attribute "data-target"
‍
- Code block: COUNTER
Please do not rename the "counter" class or the "data-target" attribute, because the code finds the elements by these names.

2. What Each Animation Does

Smooth Scroll: Makes mouse-wheel scrolling smooth and eased on desktop. It is turned off on mobile and tablet for better performance.
Number Counter: When the number scrolls into view, it counts up from 0 to the value set in "data-target". It plays only once.

3. Key Values You Can Edit

Smooth Scroll block:
‍
- duration (default 0.9): Scroll smoothness. A higher number feels slower and softer.
- min-width: 768px (default 768px): The screen width where smooth scroll turns on.
Counter block:
‍
- duration (default 2): How long the count-up takes, in seconds.
- ease (default "power1.out"): The speed curve of the count.
- start (default "top 80%"): When the count begins. "top 80%" means when the number reaches 80% down the screen.
Counter element:
‍
- data-target: The final number. To change it, select the text element in the Designer, open the Settings panel, go to Custom Attributes, and edit the "data-target" value (for example 250).

4. How to Remove an Animation

Remove Smooth Scroll:
‍
1. Go to Site Settings → Custom Code → Footer Code.
2. Delete everything from /* SMOOTH SCROLL START */ to /* SMOOTH SCROLL END */.
3. Delete the two Lenis lines at the top (the lenis script tag and the lenis stylesheet link).
4. Publish the site.
Remove Number Counter:
‍
1. Go to Site Settings → Custom Code → Footer Code.
2. Delete everything from /* COUNTER START */ to /* COUNTER END */.
3. In the Designer, select each counter text element, remove the "counter" class and the "data-target" custom attribute, and type the final number directly as text.
4. Publish the site.
Remove all GSAP animations:
‍
1. Delete the entire custom code block in Site Settings → Custom Code → Footer Code, including the GSAP script tags.
2. Remove the "counter" class and "data-target" attribute from any elements.
3. Publish the site.
